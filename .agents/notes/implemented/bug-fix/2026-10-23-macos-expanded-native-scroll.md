# Agent Note: macOS 展开候选使用虚拟化原生滚动视图

Status: implemented

## Problem

[自定义像素滚动修复](./2026-10-20-macos-expanded-candidate-smooth-scroll.md)纠正了方向、跨行跳动和裁剪，但每个像素事件仍重新测量、重建可见按钮。原生滚动需要保留可见行虚拟化、主题和选词契约，并为停在首尾后重新开始的手势提供一致的边缘反馈。

## Decision

固定首行和皮肤外框，候选区域使用透明的 `NSScrollView` 与普通非翻转文档视图。AppKit 接收精确滚动及惯性事件，负责像素位置和边界；竖向明确使用 `NSScrollElasticityAllowed`，横向关闭弹性，保留自动隐藏的原生覆盖式竖向滚动条，不让候选浮窗本身位移或取得键盘焦点。已经停在首尾后重新开始的手势仍交给 AppKit，不按 `hasPreviousPage` 或 `hasNextPage` 拦截；虚拟行定位保持在合法内容范围，但不把原生裁剪视口拉回边界，避免打断回弹。

完整重排时计算各行几何和累计高度，让滚动视图知道完整内容尺寸；仅为视口覆盖的行创建按钮。行内滚动只移动原生裁剪视口，跨行时删除离开视口的按钮、创建进入视口的按钮，其余按钮复用。普通滚轮保留旧的按行语义，键盘、带代次选词、主题、读屏和动画继续走既有控制器。

采用原生视口替代自定义事件距离累计，保留前述修复的坐标、短末页高度和选词契约。首次展开测量全部行而不是只测量可见行；窗口宽度取所有行的最大宽度，避免滚动时不断改变外框。虚拟化限制的是按钮数量，不宣称消除了全列表测量成本；超长候选列表的进一步优化需要几何缓存或估算策略。

## Verification

`shortcut-expanded-scroll` 使用正确映射 CoreGraphics 手势阶段的像素事件，等待 AppKit 异步滚动完成，再核对方向、两点跨行连续性、非等高行、结束事件、短末页及键盘和普通滚轮接管。行内滚动必须保留同一外框、滚动视图和按钮，不增加光标位置查询；跨行保留重叠按钮。二百条合成候选的按钮数量小于候选总数，原生裁剪视口定位后重画也保留手动滚动位置。

回弹回归检查竖向 `Allowed`、横向 `None`，以及停在底部后新手势仍进入原生滚动入口、原生裁剪视口确实越过底部、虚拟行定位不越界、外框高度不变。手势结束后只等待 AppKit 将视口弹回合法范围，不用程序定位伪造复位。合成事件覆盖越界和复位，但不证明真实触摸板手感，维护者仍需要分别测试连续滚到底和停稳后再向下滑。

原生宿主构建、`shortcut`、`shortcut-expanded-scroll`、`candidate-row-layout`、`candidate-expanded-grid`、`bundle-contents`、`session-smoke`、`text-client`、`desktop-input-session`、`input-source-registration`、`backend-library-load` 十项 CTest 和 `pnpm run verify-notes` 均通过；其中输入会话测试曾出现一次响应计数断言失败，单独复跑通过，不把它记作首次全绿。完整设置应用与输入法安装后签名有效，构建、设置应用内嵌和用户安装目录的核心 UUID 一致。合成事件与安装核验不等于真实触摸板惯性验收。

## Alternatives considered

- **保留自定义像素视口**：已有经过验证的最小修复，首屏只测量可见行，回退成本最低。不选它：每个像素事件重建按钮，原生视口可复用重叠按钮并将滚动与弹性边界交给 AppKit。
- **原生滚动视图一次创建全部按钮**：实现直接，AppKit 自动管理全部内容。不选它：候选数量可以很大，完整视图树会增加展开延迟和常驻内存；`NSScrollView` 不妨碍自行虚拟化按钮，不能把“不自带虚拟化”误写成“无法虚拟化”。
- **关闭全部弹性**：候选内容始终贴着边缘，不出现回弹留白。不选它：关闭竖向弹性会使停在末尾后继续向下滑没有回弹，与原生边缘反馈不一致。

## Consequences

同一行内滚动不重建候选外框、测量布局或替换按钮，跨行只更新进入和离开的行。普通滚轮和键盘保留原有语义；当前视图和候选代次检查阻止过期按钮选词。安装前保留设置应用和输入法备份，不修改用户偏好或私有词库。

首次测量所有行可能增加展开延迟和几何内存；原生滚动条可能遮住最右侧文字。竖向 `Allowed` 在全部候选都可见时也允许拖出留白，松手由 AppKit 复位。嵌套裁剪容器改变坐标层级，第三方皮肤的圆角、悬停和选中动画仍需实测。异步候选代次重载继续使用旧的定位策略，可能中断滚动；本次不改选词或重载契约。

隐藏测试面板没有 WindowServer 窗口和真实手势跟踪，直接调用 `scrollWheel:` 的合成惯性事件不能证明 AppKit 惯性位移；真实编辑器中的慢速拖动、快速惯性、反向滚动和首尾边界手感仍属于维护者的实机验收。
